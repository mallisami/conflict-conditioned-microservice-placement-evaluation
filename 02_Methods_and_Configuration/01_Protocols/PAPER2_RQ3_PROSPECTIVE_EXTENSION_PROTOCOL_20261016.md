## Purpose

The original RQ3 result at 40 independent graph identities remained unresolved at the available precision. This extension addresses two questions without changing the original result: (1) whether conflict-conditioned representation contributes after stabilization is controlled, and (2) whether the original B5-versus-B3 application-level contrast becomes more precise on 256 previously unused graph identities.

The experiment preserves the retained Stage-E environment: three K3s hosts (`rack-a`, `rack-b`, `rack-c`), the retained N=8 application generator, identical hard-admissible placement sets, the conflict-dense shared-medium scenario, high load = 2x, 5-s settle, 5-s synchronized start delay, 40-s measurement, 3-s request timeout, the retained benchmark image, CPU/memory reservations, and scheduled-request completion as the primary endpoint. ## Hybrid execution and repeatability rule

The main inferential dataset contains **one execution (replicate 1) for every graph-method condition**. Therefore the main design contains 512 Panel-A cells plus 256 Panel-B cells = **768 main-inference cells**.

A repeatability subset was frozen before outcomes using only graph identity. Within each panel, seeds were ranked by `SHA-256(PAPER2_RQ3_REPEATABILITY_SUBSET_V1_20261016:seed)` and the first 32 were selected. Those 64 graph identities receive replicates 2 and 3 in addition to replicate 1. The additional repeats contribute 256 Panel-A cells plus 128 Panel-B cells = **384 diagnostic cells**.

**Total frozen execution:** **1,152 Kubernetes cells**.

Additional repeats are used only to quantify run-to-run variability. They are **not averaged into the primary or secondary treatment-effect estimates**. All principal contrasts use replicate 1 uniformly across all graph identities. This preserves equal treatment of the N=128/N=256 graph-level units while retaining contemporaneous repeatability evidence.

## Statistics

Main contrasts use graph-paired replicate-1 values, 100,000 paired bootstrap resamples, 95% percentile confidence intervals, win/loss/tie accounting, and the frozen 0.005 practical completion threshold. The mechanism secondary family retains the prespecified Wilcoxon/Holm diagnostic. Lack of statistical significance is not labeled equivalence without a separately frozen equivalence test.

The repeatability diagnostic reports within-graph-method standard deviations over the three executions for the 64 frozen repeatability graphs. It is descriptive and does not modify the primary estimates.

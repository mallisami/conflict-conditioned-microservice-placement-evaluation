# Retained prior verification outputs

These JSON files are the selected outputs from the 18 October 2026 verification bundle. They record 36 paired-mean bootstrap interval checks with exact reported/recomputed agreement, B5 model-lock/CV-audit equivalence checks, and the frozen B3 coefficient payload's reproduction of 13,266 Stage-C group predictions (maximum absolute deviation approximately 2.78e-17).

These are archived verification outputs, not a new rerun in this release build. The original large wrapper archives and the scripts used in that earlier verification are not included in reviewer release v1.2; the outputs can be inspected and their file hashes checked, but that separate historical verification is not independently rerunnable from v1.2 alone. The original Stage-A calibration input `calibration_aggregated.csv` remains unavailable, so these outputs do not establish that the historical B3 model can be refitted from raw calibration rows.
